# Count Occurrences | Contagem de Ocorrências

## English

A beginner-friendly C program that counts how many times an integer appears in an array of five elements using a function.

### Technologies

C

### How to run

Compile with GCC:

```bash
gcc count_occurrences.c -o count_occurrences
```

Run the program:

```bash
./count_occurrences
```

### Example

If the array contains `2 5 2 8 2` and the number checked is `2`, the program displays:

```text
o número 2 aparece 3 vezes no seu vetor.
```

### What I learned

- How to create a function that counts occurrences in an array.
- How to traverse an array using a `for` loop.
- How to compare integer values and increment a counter.
- How to separate the calculation from the user interaction in `main()`.

### Future improvements

- Allow the user to choose the array size.
- Add validation for invalid or non-numeric input.
- Improve and standardize the user-facing messages.
- Allow the user to count multiple numbers without restarting the program.
